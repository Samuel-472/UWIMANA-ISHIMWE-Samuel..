# HTML Forms Assessment

This project contains a collection of HTML form pages created as part of an assessment. The pages cover common login and registration scenarios.

## Pages

- `Login.html` — login form
- `student registration.html` — student registration form
- `course registration.html` — course registration form
- `book registration.html` — book registration form

## Tools Used

- HTML
- Visual Studio Code
- Git
- GitHub

## Getting Started

Open any of the `.html` files in a web browser to view the corresponding form.
